## Controversial / Notable Windows Software Moments
- **Internet Explorer antitrust case (late 1990s–2000s)** — bundling IE with Windows led to a landmark US antitrust suit against Microsoft
- **Windows Media Player bundling** — also drew EU antitrust scrutiny, eventually forcing a version without WMP in Europe
- **Clippy (Office Assistant)** — widely mocked, became a symbol of intrusive software design
- **Windows Vista's driver/software compatibility issues** — many third-party programs broke on launch, contributing to Vista's poor reputation
- **CCleaner malware incident (2017)** — a compromised update briefly distributed malware to millions of users
- **Adobe Flash Player** — once essential Windows software, deprecated and killed off by 2020 due to security issues
